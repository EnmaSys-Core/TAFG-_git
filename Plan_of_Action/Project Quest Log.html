Quest 1: v2.0 Build (The Alchemist's Workbench)

  • Enable the "Google" sign-in provider.

  • Create the database in "production mode".

  • Paste the security rules from the blueprint to protect user data.

Phase 2: Global UI/UX (Robustness)

  • Create helpful messages for when lists are empty.

  • Add Create, Read, Update (Edit), and Delete functions for Goals & Bricks.

  • Build the "Undo" toast notification and `isDeleted` flag logic.

  • Build the global Loading spinner, Success messages, and Error handlers.

Phase 3: Core Modules (The "What")

  • Build the login/logout flow and UI.

  • Build the Goals tab (create, list, edit, delete goals).

  • Build the "One Brick" list and the "Brain Dump" auto-saving notepad.

  • Build the read-only list of completed bricks.

  • Build the slider, log button, and Chart.js line chart.
